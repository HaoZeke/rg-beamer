#+TITLE: rg-beamer
#+DESCRIPTION: Beamer + KOMA theme. Steel title field, copper lip, Source Serif 4 Display.

* What it is

A talk theme drawn as one TikZ canvas, the same way Execushares is.
The cover is a steel field. Content slides are a steel title bar with a
copper lip. Progress is that lip growing along the foot.

Type is the Execushares pairing. Titles are Source Serif 4 Display.
Slide body is Source Sans 3. Report body is Source Serif 4 on white
paper. The cover is the IPAM working-group architecture
(left bar, bottom bar, open field) in steel and copper.
Body pages keep eisvogel head and foot rules.

Not Metropolis. Not seahorse. Not a stripe on empty paper.

* Use from TeX

#+begin_src bash
export TEXINPUTS="$HOME/Git/Github/TeX/rg-beamer/theme:"
#+end_src

#+begin_src latex
\documentclass[aspectratio=169,11pt]{beamer}
\usepackage{fontspec}
\usetheme{rg}
#+end_src

=noprogress= fills the foot bar. Frame option =standout= is a steel
field, same option as Metropolis. =\institute= is the footer mark.

Report:

#+begin_src latex
\documentclass[12pt,a4paper,oneside,headinclude]{scrartcl}
\usepackage{fontspec}
\usepackage{rg-report}
\rgreportmark{short head}{date}{footer}
\rggrant{EINF-13109}
\rgseries{SURF PromApp}
\rgfor{the PI}
\rgcoverimage{hero.png}
\rgcoverlogos{org-logo.pdf}{code-logo.pdf}
#+end_src

Build with xelatex. fontspec is loaded by the document, not by the
theme.

* Use from Org / Doom

1. Load the helper once in =config.org=:

   #+begin_src emacs-lisp
   (load! "~/Git/Github/TeX/rg-beamer/emacs/rg-beamer.el")
   #+end_src

2. Snippets next to the Metropolis one:

   #+begin_src bash
   ln -s ~/Git/Github/TeX/rg-beamer/emacs/org-beamer-rg \
     ~/.config/doom/snippets/org-mode/org-beamer-rg
   ln -s ~/Git/Github/TeX/rg-beamer/emacs/org-report-rg \
     ~/.config/doom/snippets/org-mode/org-report-rg
   #+end_src

   Keys: =<orgbbmrrg= (slides), =<orgrg= (report).

* Layout

| Element | Treatment |
|---+---|
| Title page | steel field on the top, copper lip, title in paper |
| Frame title | white Display type in the steel bar |
| Progress | copper growing in the foot bar |
| Block | copper left rule |
| Item | copper square |
| Standout | steel field, paper type |
| Report cover | steel left bar, copper lip and foot bar, Display title |
| Report body | white paper, 0.4pt head and foot rules |

16:9. No navigation chrome.
