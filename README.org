#+TITLE: rg-beamer
#+DESCRIPTION: Beamer + KOMA theme. Copper spine, Source Serif 4 Display, Source Sans 3.

* What it is

A talk theme and a report companion that share one mark: a copper
spine on the left edge. On slides the spine is the progress bar. On
paper it is just the spine.

Type is the pairing already used in Execushares. Titles are Source
Serif 4 Display. Slide body is Source Sans 3. Report body is Source
Serif 4. Mono is Source Code Pro. Colour is cool lab paper, steel
ink, and one copper.

Not Metropolis (no title slab, no Fira). Not seahorse. Not a
three-colour swap on someone else's canvas.

* Use from TeX

#+begin_src bash
export TEXINPUTS="$HOME/Git/Github/TeX/rg-beamer/theme:"
#+end_src

#+begin_src latex
\documentclass[aspectratio=169,11pt]{beamer}
\usepackage{fontspec}
\usetheme{rg}
#+end_src

=noprogress= is accepted and currently unused: the spine is the
progress. Frame option =standout= still inverts to steel, same as
Metropolis.

Report:

#+begin_src latex
\documentclass[12pt,a4paper,oneside,headinclude]{scrartcl}
\usepackage{fontspec}
\usepackage{rg-report}
\rgreportmark{short head}{date}{footer}
#+end_src

Build with xelatex. fontspec is loaded by the document, not by the
theme.

* Use from Org / Doom

1. Load the helper once in =config.org=:

   #+begin_src emacs-lisp
   (load! "~/Git/Github/TeX/rg-beamer/emacs/rg-beamer.el")
   #+end_src

2. Snippets next to the Metropolis one:

   #+begin_src bash
   ln -s ~/Git/Github/TeX/rg-beamer/emacs/org-beamer-rg \
     ~/.config/doom/snippets/org-mode/org-beamer-rg
   ln -s ~/Git/Github/TeX/rg-beamer/emacs/org-report-rg \
     ~/.config/doom/snippets/org-mode/org-report-rg
   #+end_src

   Keys: =<orgbbmrrg= (slides), =<orgrg= (report). Same after-save
   hook as =orgBeamerMetropolis=.

3. Or set =#+LaTeX_CLASS: rg-beamer= / =rg-report=.
   =BEAMER_opt: standout= still works. =\institute= is the slide
   footer mark.

* Layout

| Element | Treatment |
|---+---|
| Title page | paper, steel serif title, no rule, full-height spine |
| Frame title | Source Serif 4 Display, no underline |
| Progress | copper spine filling from the foot |
| Block | copper left rule, title in the display face |
| Item | copper square |
| Standout | steel field, paper type, full spine |
| Report title | display serif, copper HRule, italic author |
| Report page | the same spine, sans running head |

16:9. Left-aligned. No navigation chrome.
